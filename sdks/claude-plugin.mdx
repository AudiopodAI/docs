<Info>
**What is the AudioPod plugin?** It brings AudioPod tools into Claude Code. The plugin adds skills and slash commands that call the AudioPod [MCP server](/sdks/mcp) at `https://mcp.audiopod.ai`, so you can transcribe, split stems, or make a voiceover without leaving your session.
</Info>

## Install

In Claude Code, run:

```
/plugin marketplace add AudiopodAI/claude-plugin
/plugin install audiopod@audiopod
```

The first time Claude uses an AudioPod tool it asks you to connect. Choose Connect, or run `/mcp`, select AudioPod and choose Authenticate. A browser window opens, you sign in to your AudioPod account, review what the connection can do, and choose Allow access. There's no API key to copy. You can disconnect at any time from your AudioPod account page.

### Using an API key instead (CI or headless)

[Create a key in your dashboard](https://audiopod.ai/dashboard/account/api-keys), then run:

```
claude mcp add --transport http audiopod https://mcp.audiopod.ai --header "X-API-Key: <your key>"
```

Use `https://mcp.audiopod.ai/core` instead for the `audiopod-transcribe` tool set. The key is added separately from the plugin, and the plugin's skills still work with it.

## The two plugins

| Plugin | What it covers | Endpoint |
|------|-------------|----------|
| `audiopod` | Transcription, stem separation, noise removal, speaker separation, audio-to-MIDI, media conversion, text to speech, music generation, and voice cloning and changing. | `https://mcp.audiopod.ai` |
| `audiopod-transcribe` | Transcription and audio tools only. | `https://mcp.audiopod.ai/core` |

Install `audiopod-transcribe` the same way with `/plugin install audiopod-transcribe@audiopod`.

## Commands

| Command | Example |
|---------|---------|
| `/audiopod:transcribe` | `/audiopod:transcribe https://example.com/interview.mp3 srt` |
| `/audiopod:stems` | `/audiopod:stems https://example.com/song.mp3 4stem` |
| `/audiopod:tts` | `/audiopod:tts "Welcome to the show" British English` |
| `/audiopod:status` | `/audiopod:status <job-id> transcribe` |

`/audiopod:tts` is available in the `audiopod` plugin only. You can also ask in plain language, like "remove the background noise from this clip", and the matching skill picks it up.

## How jobs work

AudioPod jobs run asynchronously. Claude starts the job, polls its status until it finishes, and hands you the output links. Output links expire after 1 hour. If one has expired, ask again (or run `/audiopod:status <job-id> <tool>`, since job ids are unique per tool) for fresh links.

## Credits

Jobs use your AudioPod account's credits. See [pricing](https://audiopod.ai/pricing) for plans and credit details.

## Privacy

Audio you send is processed on AudioPod's servers under the [AudioPod privacy policy](https://audiopod.ai/privacy).

## Troubleshooting

| Symptom | Fix |
|---------|-----|
| Claude says AudioPod isn't connected or the connection expired | Run `/mcp`, select AudioPod and choose Authenticate. |
| `402` | Your account doesn't have enough credits for the job. Top up or upgrade on the [pricing page](https://audiopod.ai/pricing). |
| Tools not showing up | Run `/mcp` to check the connection status of the AudioPod server. |
| The browser sign-in page doesn't open (remote or headless machine) | Copy the URL Claude shows into a browser on any machine, or use the API-key option above. |
