<Info>
**What is the AudioPod plugin?** It brings AudioPod tools into Claude Code. The plugin adds skills and slash commands that call the AudioPod [MCP server](/sdks/mcp), so you can transcribe, split stems, or turn a recording into MIDI without leaving your session. There are two plugins: `audiopod` (the main plugin) and `audiopod-studio` (the full toolkit).
</Info>

## Install

In Claude Code, run:

```
/plugin marketplace add AudiopodAI/claude-plugin
/plugin install audiopod@audiopod
```

For the full toolkit, install `audiopod-studio` instead:

```
/plugin install audiopod-studio@audiopod
```

Install one of them, not both. Both register an MCP server named `audiopod`, so installing both would duplicate the tools.

The first time Claude uses an AudioPod tool it asks you to connect. Choose Connect, or run `/mcp`, select AudioPod and choose Authenticate. A browser window opens, you sign in to your AudioPod account, review what the connection can do, and choose Allow access. There's no API key to copy. You can disconnect at any time from your AudioPod account page.

### Using an API key instead (CI or headless)

[Create a key in your dashboard](https://audiopod.ai/dashboard/account/api-keys), then run:

```
claude mcp add --transport http audiopod https://mcp.audiopod.ai/core --header "X-API-Key: <your key>"
```

That is the endpoint for the main `audiopod` plugin. For `audiopod-studio`, use `https://mcp.audiopod.ai` instead. The key is added separately from the plugin, and the plugin's skills still work with it.

## The two plugins

| Plugin | What it covers | Endpoint |
|------|-------------|----------|
| `audiopod` (AudioPod) | The main plugin: transcription (speaker labels, SRT/VTT/TXT), stem separation, noise removal, speaker separation, format conversion and audio-to-MIDI. | `https://mcp.audiopod.ai/core` |
| `audiopod-studio` (AudioPod Studio) | The full toolkit: everything in `audiopod` plus music, text to speech and voice tools. | `https://mcp.audiopod.ai` |

## Commands

| `audiopod` command | `audiopod-studio` command | Example |
|---------|---------|---------|
| `/audiopod:transcribe` | `/audiopod-studio:transcribe` | `/audiopod:transcribe https://example.com/interview.mp3 srt` |
| `/audiopod:stems` | `/audiopod-studio:stems` | `/audiopod:stems https://example.com/song.mp3 4stem` |
| `/audiopod:midi` | `/audiopod-studio:midi` | `/audiopod:midi https://example.com/melody.mp3` |
| `/audiopod:status` | `/audiopod-studio:status` | `/audiopod:status <job-id> transcribe` |
| not available | `/audiopod-studio:tts` | `/audiopod-studio:tts "Welcome to the show" British English` |

`/audiopod-studio:tts` exists only in the `audiopod-studio` plugin. You can also ask in plain language, like "remove the background noise from this clip", and the matching skill picks it up.

## How jobs work

AudioPod jobs run asynchronously. Claude starts the job, polls its status until it finishes, and hands you the output links. Output links expire after 1 hour. If one has expired, ask again (or run `/audiopod:status <job-id> <tool>` or `/audiopod-studio:status <job-id> <tool>`, since job ids are unique per tool) for fresh links.

## Credits

Jobs use your AudioPod account's credits. See [pricing](https://audiopod.ai/pricing) for plans and credit details.

## Privacy

Audio you send is processed on AudioPod's servers under the [AudioPod privacy policy](https://audiopod.ai/privacy).

## Troubleshooting

| Symptom | Fix |
|---------|-----|
| Claude says AudioPod isn't connected or the connection expired | Run `/mcp`, select AudioPod and choose Authenticate. |
| `402` | Your account doesn't have enough credits for the job. Top up or upgrade on the [pricing page](https://audiopod.ai/pricing). |
| Tools not showing up | Run `/mcp` to check the connection status of the AudioPod server. |
| The browser sign-in page doesn't open (remote or headless machine) | Copy the URL Claude shows into a browser on any machine, or use the API-key option above. |
